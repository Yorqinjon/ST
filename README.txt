Приглашение на суннат-той Мухаммадзиё — файлы для GitHub Pages

Сайт из 3 файлов: index.html, music.mp3, preview.jpg

1. github.com → New repository (например: sunnat-toy) → Public → Create repository.
2. «uploading an existing file» → перетащите 3 файла → Commit changes.
3. Settings → Pages → Deploy from a branch → main, / (root) → Save.
4. Через 1–2 минуты сайт откроется: https://ВАШ_ЛОГИН.github.io/sunnat-toy/
